# Политика безопасности

## Поддерживаемые версии

Исправления безопасности попадают в ветку `main` и в последний релиз. До версии 1.0.0 исправления получает только последняя минорная версия (сейчас 0.1.x).

## Сообщить об уязвимости

Сообщайте об уязвимостях в закрытом порядке через GitHub Private Vulnerability Reporting. Откройте вкладку **Security** репозитория [it-koval/cms](https://github.com/it-koval/cms) и выберите **Report a vulnerability**. Не создавайте публичный issue или pull request для проблемы безопасности и не публикуйте её в обсуждениях.

Опишите:

- что затронуто (админка, JSON API, публичные страницы, MCP-сервер или команды установки) и версию или коммит;
- как воспроизвести проблему, лучше всего на минимальной конфигурации сайта, где она проявляется;
- что получает атакующий.

Мы читаем каждое сообщение, отвечаем в закрытой переписке и держим вас в курсе исправления. До версии 1.0.0 мы не обещаем сроков ответа. Когда исправление выйдет, мы упомянем вас, если вы этого хотите.

## Область действия

Бандл поставляет админку, JSON API под адресом админки, публичные маршруты (страницы, заявки из форм, `/healthz`, `/mcp`, `/sitemap.xml`, `/robots.txt`, `/llms.txt`, файл ключа IndexNow и копии изображений) и консольные команды. О проблемах в коде вашего сайта, в Symfony или в других зависимостях сообщайте их сопровождающим. Если конфигурация бандла делает такую проблему хуже, сообщите и нам.

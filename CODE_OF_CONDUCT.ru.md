# Кодекс поведения

Относитесь к другим с уважением. Приветствуйте новых участников и разные мнения. Обсуждайте работу и объясняйте, как её улучшить.

Недопустимы преследование, угрозы, оскорбления, дискриминация и публикация чужих личных данных без согласия. Правила действуют в задачах, pull request, ревью и других пространствах проекта.

Чтобы связаться с сопровождающими, создайте задачу и попросите связаться с вами в личном порядке. Не указывайте в открытой задаче имена и чувствительные сведения. Сообщить о нарушении на GitHub в закрытом порядке можно через [поддержку GitHub](https://support.github.com/contact/report-abuse).

Сопровождающие разбирают обращения. Они могут удалить материалы, вынести предупреждение или ограничить доступ. Сведения из обращения передают только тем, кому они нужны для разбора.

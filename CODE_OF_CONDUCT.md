# Code of conduct

Treat others with respect. Welcome new contributors and different perspectives. Give feedback on the work and explain how it can improve.

Harassment, threats, insults, discrimination, and sharing someone’s private information without consent are unacceptable. These rules apply to issues, pull requests, reviews, and other project spaces.

To reach the maintainers, open an issue and ask for a private follow-up. Keep names and sensitive details out of the public issue. You can report abuse on GitHub privately through [GitHub Support](https://support.github.com/contact/report-abuse).

Maintainers review reports and may remove content, warn people, or restrict access. They share report details only as needed to handle the case.

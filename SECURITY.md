# Политика безопасности

## Поддерживаемые версии

ITK CMS находится в альфе, релизов пока нет. Исправления делаются в ветке `main` и, когда появятся релизы, в последнем релизе.

## Сообщить об уязвимости

Сообщайте об уязвимостях в частном порядке через GitHub Private Vulnerability Reporting: откройте вкладку **Security** этого репозитория и выберите **Report a vulnerability**. Не создавайте публичный issue или pull request для проблемы безопасности и не публикуйте её в обсуждениях.

Опишите:

- что затронуто (админка, JSON API, публичные страницы, MCP-сервер, команды установки) и версию или коммит;
- как воспроизвести проблему, лучше всего на минимальной конфигурации сайта, где она проявляется;
- что получает атакующий.

Мы прочитаем сообщение, ответим в закрытой переписке и будем держать вас в курсе исправления. Пока проект в альфе, сроков ответа мы не обещаем. Когда исправление выйдет, мы с радостью упомянем вас, если вы этого хотите.

## Область действия

Бандл поставляет панель администратора, JSON API под адресом админки, публичные маршруты (страницы, заявки из форм, `/healthz`, `/mcp`, копии изображений) и консольные команды. О проблемах в коде вашего сайта, в Symfony или в других зависимостях сообщайте их сопровождающим; сообщите и нам, если конфигурация бандла делает проблему хуже.
